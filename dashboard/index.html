How this radar values a launch

Most radars price every future token with one flat guess. This one asks the market instead. The snapshot holds protocols whose tokens already trade; for each category it takes the median market-cap per dollar of TVL those live peers actually trade at, and values a pre-token protocol at its own TVL times its category's median, adjusted for its 7-day TVL momentum and for how long it has run with no token. Categories with fewer than three live peers fall back to the market-wide median. No protocol name is ever special-cased: one function scores every row.

Every row then earns a verdict from its implied value and momentum alone: FARM FIRST (implied value at least $100M), STRONG WATCH (at least $25M), WATCH (at least $5M), LONG SHOT (below that). The board covers the whole watchlist and adds the strongest pre-token protocols below its $50M floor, picked by implied value under the same launch test: no token yet, and not a wrapped, staked or bridged product of one that trades. Protocols whose token already trades are kept apart in the Live list, at the market's own values.

Built from one sealed DefiLlama snapshot. The page runs with no network; every figure it shows is computed from that snapshot.
